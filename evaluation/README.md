# EKG Evaluation

This tree contains target-owned, reproducible, non-clinical evaluation contracts: dataset identity, split/leakage controls, annotation comparison, robustness, fixtures, benchmark definitions, and failure modes.

Evaluation artifacts do **not** create project clinical gold, admit evidence, report diagnostic performance, or activate diagnostic runtime. Source labels remain source labels. Metrics remain `NOT_REPORTABLE` while approved adjudicated project gold count is zero.

Canonical evaluation code is brand-neutral. Donor identities appear only in provenance arrays and audit records.
