# Image decoder dependencies

`requirements-image.txt` pins Pillow 12.3.0 and pypdfium2 5.13.0. They are installed dependencies; no donor source, weights, real ECG datasets or credential material are imported. Implementation code in the image operator is target-authored. Artifact records include installed wrapper versions, the PDFium binary version and implementation hashes; pinning the wrapper version alone is not a binary hash admission rule.

[Pillow's upstream documentation](https://pillow.readthedocs.io/en/stable/about.html) describes its license and project. Keep Pillow's distributed LICENSE and dependency notices when packaging it. [ImageOps documentation](https://pillow.readthedocs.io/en/stable/reference/ImageOps.html) documents EXIF transpose; original metadata is retained only in the preserved original, and new raster outputs are RGB images without copied EXIF.

[pypdfium2's upstream licensing section](https://pypdfium2.readthedocs.io/en/stable/readme.html#licensing) separates wrapper licensing (Apache-2.0/BSD-3-Clause), PDFium licensing, other binary dependency notices and documentation licensing. Its installed wheel contains PDFium and associated license files; preserve those distributed notices and verify the exact wheel/binary assets before distributing a product. Do not treat wrapper licensing as a license for every bundled binary or model/data asset. This document is a dependency record, not a completed commercial distribution review.

[pypdfium2's API reference](https://pypdfium2.readthedocs.io/en/stable/python_api.html) defines page rendering and resource lifecycle. The operator closes documents, pages and bitmaps explicitly. Native decoder code runs in a spawned worker with bounded inputs/pages/pixels and a wall-clock deadline. It is not a security sandbox with an OS memory ceiling. PDF scripts are not executed by this operator, but malformed native-decoder inputs remain a deployment security consideration. Use a private local store; a network-facing deployment needs isolation and access control before exposing this CLI as a service.
