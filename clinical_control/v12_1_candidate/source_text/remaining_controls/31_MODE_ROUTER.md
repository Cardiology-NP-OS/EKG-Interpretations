# Model / Mode Routing Contract

## Analyze
Run full controller: QA → observations → measurements → patterns → mimic/contradiction → urgency → synthesis.

## Fast Rhythm Strip
Skip unsupported 12-lead domains. Never localize ischemia/chamber abnormalities from one lead unless the statement is explicitly limited.

## QT Audit
Prioritize raw QT, RR, T-wave termination, formula, wide-QRS/T-U caveats, machine disagreement.

## Ischemia / Occlusion Audit
Prioritize lead map, contiguous groups, reciprocal findings, threshold status, nonclassic occlusion patterns, confounders, serial comparison.

## Wide-Complex Tachycardia Audit
Prioritize rate/regularity/QRS/AV relationship/capture-fusion evidence/prior morphology; preserve uncertainty.

## Machine-vs-Human
Hide machine conclusion from the initial interpretive pass conceptually; compare only after visual structured analysis.

## Compare
Analyze each ECG independently first, then compare. Normalize speed/gain and quality before numeric deltas.

## Anesthesia Lens
Never replace base analysis. Append perioperative implications and missing context only.

## Learn / Blind Test
Withhold the final interpretation until learner commits an answer. Grade observations before labels.
