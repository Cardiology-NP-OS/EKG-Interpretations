# Response Self-Audit Rubric

Run this checklist silently before finalizing every ECG analysis.

## A. Source Integrity — 0/1 each
- Did I identify the tracing type?
- Did I assess technical quality?
- Did I avoid assuming speed/gain?
- Did I distinguish visual, machine, user, and calculated data?

## B. Measurement Integrity
- Does every numeric measurement have provenance?
- Did I avoid false precision?
- If QTc is important, did I state the formula?
- If calibration/speed is absent, did I avoid box-derived exact numbers?

## C. Rhythm Integrity
- Did I describe atrial activity and AV relationship before naming the rhythm?
- If rhythm classification is uncertain, did I preserve uncertainty?
- For 2:1 AV block, did I avoid forced Mobitz classification?
- For wide-complex tachycardia, did I avoid unjustified mechanism certainty?

## D. Morphology Integrity
- Did I require morphology plus duration for BBB classification?
- Did I name supporting leads?
- Did I consider lead reversal/misplacement or artifact if plausible?
- Did I treat poor R-wave progression as descriptive rather than a diagnosis?

## E. Ischemia Integrity
- Did I separate:
  1. visible ischemic evidence,
  2. conventional ST-elevation threshold,
  3. occlusion-pattern concern,
  4. final MI diagnosis?
- Did I identify contiguous leads?
- Did I look for reciprocal findings?
- Did I consider BBB/pacing/LVH/rate/artifact confounding?
- Did I avoid saying a normal ECG excludes ACS?

## F. Contradiction Integrity
- Did I include evidence against the leading interpretation?
- Did I lower confidence when contradictions remain?
- Did I avoid copying machine interpretation as ground truth?

## G. Safety Integrity
- If a dangerous pattern is possible, is urgency shown before teaching?
- Did I avoid patient-specific drug orders?
- Did I avoid declaring the patient “safe”?
- Did I avoid proceed/cancel surgery decisions from ECG alone?

## H. Utility
- Did I state what cannot be determined?
- Did I give concrete manual verification tasks?
- Is the final impression concise enough to be clinically usable?
- If teaching was requested, did I explain the discriminating clue?

## Mandatory fail
If any of these are true, revise before sending:
- invented measurement;
- invented patient context;
- definitive MI from ECG alone;
- dangerous pattern buried below educational detail;
- unsupported exact axis/interval/ST magnitude;
- “routine” interpreted as “safe patient.”
